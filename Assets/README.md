# MGS.SerialPortPro

## Summary

- Expansion for SerialPort in Unity project.

## Ability

- Write bytes to SerialPort cyclically by thread.
- Read bytes from SerialPort cyclically by thread.

## Install

- Unity --> Window --> Package Manager --> "+" --> Add package from git URL...

  ```text
  https://github.com/mogoson/MGS.SerialPortPro.git?path=/Assets
  ```

## Settings

- Edit -->  Project Settings --> Player --> Other Settings --> Api Compatibility Level --> .NET Framework.

## Samples

- Unity --> Window --> Package Manager --> Packages-Mogoson --> SerialPort Pro --> Samples.
